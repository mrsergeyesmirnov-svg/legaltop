# LEGAL.TOP

Независимая статическая версия сайта https://legal.top, подготовленная для ухода с Tilda.

## Что внутри

- `index.html` — основной сайт
- `styles.css` — визуальная система и адаптив
- `script.js` — мобильное меню, sticky-header и reveal-анимации
- `privacy.html` — политика конфиденциальности
- `404.html` — fallback и перенаправления со старых URL Tilda
- `CNAME` — пользовательский домен `legal.top`
- `robots.txt`, `sitemap.xml` — базовая SEO-инфраструктура

## Публикация через GitHub Pages

1. В репозитории открыть Settings → Pages.
2. Выбрать публикацию из ветки `main`, папка `/ (root)`.
3. После появления адреса GitHub Pages настроить DNS домена `legal.top` по инструкции GitHub Pages для apex-домена.
4. В Pages указать custom domain `legal.top` и включить HTTPS после успешной проверки DNS.

До переключения DNS текущий сайт на Tilda продолжит открываться по домену.
